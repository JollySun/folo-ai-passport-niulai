# 使用说明

## 安装前

本固件只面向 ESP32-C3 FoloToy AI Passport。首次安装必须使用发布包中的 `*-full.bin`，否则自定义录音不可用。已经安装过本项目完整固件的设备可以只更新 `*-app.bin`。

安装前请注意：

- 自定义录音最多两份，每份最长 10 秒。
- 重置声音会删除两份自定义录音，无法撤销。
- 代码许可证不代表拥有电影素材的再分发权；公开分发前阅读[素材说明](../assets/niulai/SOURCES.md)。

烧录命令见[构建说明](BUILDING.md)，也可以使用 FoloToy 的 [Web Flasher](https://ai-passport.folotoy.cn/tools/web-flasher) 选择下载的固件文件。

## 页面与按键

首页显示《牛来》海报、操作提示和左上角电量。任意非设置页面短按上键进入牛来页，短按下键进入妈妈页；重复短按会再次播放对应声音和动画。

| 操作 | 结果 |
| --- | --- |
| 短按上键 | 牛来动画 + “妈妈～～”声音 |
| 短按下键 | 妈妈动画 + “牛来！”声音 |
| 短按确认键 | 打开设置；在设置中激活或取消当前选项 |
| 长按确认键 | 非设置页面停止当前音频并回到首页；设置页返回原页面 |

在 1.8 秒内连续按同一个角色键，字幕和动画会变得更急切；在同一时间内交替按上键和下键，字幕框会用两个角色色交替闪动，形成接话效果。原有单次播放行为不变。

播放自定义声音时，录音播放结束后动画会同步停止。

设备连续 30 秒无操作且未在录音时会进入省电待机：屏幕面板、音频链路和动画定时器会暂停，字幕内容不会改变。之后第一次完整按键只负责唤醒，并恢复用户设置的亮度，不会播放、录音或进入设置。若从进入待机起继续无操作至总计 5 分钟，ESP32-C3 会进入深睡；GPIO0 的低电平按键可唤醒设备并重启应用。Flash 中的录音和设置会保留，但当前页面、动画和形象变体等运行时状态会回到启动默认值。

设置页有音量、亮度和恢复默认声音三个选项。未激活选项时，上键 / 下键切换选项；按确认键激活音量或亮度后，上键 / 下键调整数值，再按确认键取消激活。页面底部第二行始终显示“长按确认键返回”，长按确认键会返回进入设置前的页面。

音量以 5% 步长调整，范围为 0–100%，只改变播放音量，不会改变自定义录音。亮度以 10% 步长调整，范围为 20–100%，调整后立即生效。音量和亮度会保存，重启后继续使用；首次启动的默认值分别为 45% 和 70%。

## 录制自己的声音

1. 短按上键进入牛来页，或短按下键进入妈妈页。
2. 在牛来页长按上键；在妈妈页长按下键。
3. 页面出现“正在录音”后说话。
4. 松开按键保存；达到 10 秒时也会自动结束。
5. 页面显示“录音已保存”后，再次短按对应方向键试听。

只有完整保存成功后，新录音才会替换旧录音；保存失败或意外中断时，上一份有效录音仍会保留。

在设置页选中“恢复默认声音”并按确认键后，页面会要求再次确认；再次按确认键才会删除两份自定义录音并恢复内置声音。按上键或下键可取消确认。看到“已恢复默认声音”表示完成。

## 电量显示

电量图标优先读取 CW2017 的 SOC。SOC 无效时，固件读取电池电压并进行近似换算；芯片不可用或总线读取失败时，图标显示为空，不影响动画和按键。

电压估算不是校准后的电池容量，低温、负载和电池老化都可能导致偏差。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 显示“录音存储不可用” | 使用 `*-full.bin` 重新安装完整固件 |
| 显示“录音失败” | 确认音频硬件可用，重启后缩短录音重试 |
| 调整音量听不出变化 | 确认不为 0%，退出设置后重新触发播放 |
| 电量图标为空 | 检查 CW2017/I2C；应用仍可正常使用 |
| 开机无画面 | 确认固件型号和烧录地址，查看 USB Serial/JTAG 日志 |
| 自定义声音异常 | 在设置页选中“恢复默认声音”，连续确认两次后重新录制 |
