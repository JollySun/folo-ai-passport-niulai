# 使用说明

## 安装前

本固件只面向 ESP32-C3 FoloToy AI Passport。首次安装必须使用发布包中的 `*-full.bin`，因为自定义录音依赖专用 `recordings` 分区。已经烧录过相同分区表的设备可以只更新 `*-app.bin`。

安装前请注意：

- 自定义录音最多两份，每份最长 10 秒，16 kHz、16 bit、单声道。
- 重置声音会删除两份自定义录音，无法撤销。
- 代码许可证不代表拥有电影素材的再分发权；公开分发前阅读[素材说明](../assets/niulai/SOURCES.md)。

烧录命令见[构建说明](BUILDING.md)，也可以使用 FoloToy 的 [Web Flasher](https://ai-passport.folotoy.cn/tools/web-flasher) 选择下载的固件文件。

## 页面与按键

首页显示海报、操作提示和左上角电量。任意非设置页面短按上键进入牛来页，短按下键进入妈妈页；重复短按会再次播放对应声音和动画。

| 操作 | 结果 |
| --- | --- |
| 短按上键 | 牛来动画 + “妈妈～～”声音 |
| 短按下键 | 妈妈动画 + “牛来！”声音 |
| 短按确认键 | 打开设置；再次短按返回原页面 |
| 长按确认键 | 停止当前音频并回到首页 |

设置页使用上键 / 下键以 5% 步长调整音量，范围为 0–100%。音量只影响播放，不影响录音采样。

## 录制自己的声音

1. 短按上键进入牛来页，或短按下键进入妈妈页。
2. 在牛来页长按上键；在妈妈页长按下键。
3. 页面出现“正在录音”后说话。
4. 松开按键保存；达到 10 秒时也会自动结束。
5. 页面显示“录音已保存”后，再次短按对应方向键试听。

录制期间会流式写入备用 Bank。只有完整保存成功后，新 Bank 才会成为有效录音；写入失败时上一份有效录音仍保留。

在设置页双击确认键可删除两份自定义录音并恢复内置声音。看到“已恢复默认声音”表示完成。

## 电量显示

电量图标优先读取 CW2017 的 SOC。SOC 无效时，固件读取电池电压并进行近似换算；芯片不可用或总线读取失败时，图标显示为空，不影响动画和按键。

电压估算不是校准后的电池容量，低温、负载和电池老化都可能导致偏差。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 显示“录音存储不可用” | 使用 `*-full.bin` 重新烧录分区表和固件 |
| 显示“录音失败” | 确认音频硬件可用，重启后缩短录音重试 |
| 调整音量听不出变化 | 确认不为 0%，退出设置后重新触发播放 |
| 电量图标为空 | 检查 CW2017/I2C；应用仍可正常使用 |
| 开机无画面 | 确认固件型号和烧录地址，查看 USB Serial/JTAG 日志 |
| 自定义声音异常 | 在设置页双击确认键恢复默认声音后重新录制 |
