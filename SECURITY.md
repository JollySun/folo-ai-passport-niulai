# Security Policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch. Older firmware versions are not maintained separately.

## Reporting a vulnerability

Do not open a public issue for a vulnerability, private recording, credential, or sensitive device log. Use [GitHub private vulnerability reporting](https://github.com/JollySun/folo-ai-passport-niulai/security/advisories/new) and include:

- affected firmware version or commit;
- hardware revision, if relevant;
- reproduction steps and impact;
- a minimal proof of concept without copyrighted or personal audio.

You should receive an acknowledgment within seven days. Please allow time for validation and a coordinated fix before public disclosure.

## Scope

Relevant reports include malformed flash data, unsafe partition access, unintended recording disclosure, memory corruption, and vulnerabilities introduced by dependencies. Physical access attacks and rights issues in third-party media are tracked separately from code security.
